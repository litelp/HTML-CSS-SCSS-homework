### Notes

- In task 3, the responsive layout of the flex cards is implemented using media queries rather than the `flex: 1 1 200px;` property, as this ensures that their resizing happens simultaneously with the grid cards.

### Technologies Used

- **HTML** — markup language used to build the structure and semantic layout of the application pages
- **SCSS** — CSS preprocessor used to write styles in a more structured and maintainable way with variables, nesting, and reusable mixins
